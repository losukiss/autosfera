AUTOSFERA — версия для GitHub Pages (демо-просмотр)

ВАЖНО
Это статическая демонстрационная версия для показа внешнего вида сайта. GitHub Pages не запускает Node.js и SQLite. Форма записи показывает сообщение о демо-режиме; реальные заявки не отправляются и не сохраняются. Админ-панель отключена.

ПУБЛИКАЦИЯ
1. Откройте https://github.com/new
2. Repository name: AUTOSFERA (или другое имя). Выберите Public.
3. Нажмите Create repository.
4. Внутри нового репозитория нажмите Add file → Upload files.
5. Распакуйте этот ZIP на компьютере и перетащите СОДЕРЖИМОЕ папки AUTOSFERA-GitHub-Pages в окно загрузки GitHub. Файл index.html должен лежать в корне репозитория, а папка assets — рядом с ним. Не загружайте исходный сервер server.js или базу данных.
6. Нажмите Commit changes.
7. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch.
8. Branch: main; Folder: /(root), затем Save.
9. Подождите несколько минут и обновите Settings → Pages. Там появится ссылка Visit site.

Адрес будет примерно таким: https://ВАШ-ЛОГИН.github.io/AUTOSFERA/

При публикации сайт и файлы публичны. Не загружайте пароли, базу данных или личные данные клиентов.
